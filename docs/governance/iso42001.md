# ISO/IEC 42001:2023 (AI Management System) Mapping (Task 047, HUMAN-gated)

**Scope.** This document maps the relevant management-system clauses
(4–10) and Annex A controls of ISO/IEC 42001:2023 to concrete
artifacts in this repository, and explicitly notes where the standard
— written for organizational AI management systems — has a **gap with
respect to agentic, multi-agent AI**, which this artifact's pattern
catalog addresses structurally.

ISO/IEC 42001 is a *management system* standard (an AIMS): most of its
clauses concern organizational processes, which a research artifact
can only illustrate. The mapping therefore distinguishes between
artifacts that *implement* a control mechanism and artifacts that
merely *document* one.

## The agentic-AI gap (explicit note)

ISO/IEC 42001:2023 was drafted for organizations managing AI systems
generally; it predates the current generation of **multi-agent,
tool-using, orchestrated GAI systems** and therefore does not address,
at control granularity:

1. **Inter-agent coordination risk** — failures that arise from the
   *composition* of agents (supervisor fan-out, pipelines,
   choreography) rather than from any single model. This artifact's
   fault campaign (`figures/fault_matrix.png`) measures exactly this
   compositional risk surface, per coordination pattern.
2. **Oversight placement within an agent chain** — Annex A.9 requires
   human oversight but is silent on *where* in a multi-agent chain the
   oversight node must sit. The catalog's P6 pattern and the decision
   tree (`figures/decision_tree.png`) make placement an explicit
   design decision.
3. **Cross-platform agent federation** — the standard's third-party
   controls (A.10) assume conventional supplier relationships, not a
   live bridge between two agentic runtimes with identity propagation
   (P7).

The pattern catalog can be read as a candidate *technical
complement*: it supplies the structural vocabulary (patterns,
consequences, governance hooks) that an AIMS needs in order to apply
clause 6 risk treatment and Annex A.9 oversight controls to agentic
systems specifically.
